# Bezpečnost SwiDe

## Soukromé hlášení

Pokud editor zpřístupní cizí projekt, zobrazí artefakt jiného sestavení nebo může odhalit GitHub token či podpisový klíč, přihlas se na GitHub a [otevři soukromé hlášení zranitelnosti](https://github.com/HappyMistake64/Xcode-for-iphone/security/advisories/new). Tento formulář předá hlášení správcům repozitáře. Technické podrobnosti sdílej v něm.

Uveď verzi editoru nebo commit, zda šlo o Safari či nativní editor, očekávané a skutečné chování a možný dopad. Pokud už máš ukázku, stačí malý vlastní testovací projekt a upravený výpis. U záměny výsledků může pomoci identifikátor vlastního požadavku a běhu GitHub Actions.

## Co sdílet

Před přiložením snímku nebo logu odstraň tokeny, podpisové klíče, přihlašovací údaje a cizí zdrojové soubory. U již zveřejněného GitHub tokenu jej co nejdříve zneplatni v nastavení svého účtu. K popisu problému stačí druh údaje a místo, kde se objevil.

Běžné selhání kompilace, importu nebo instalace můžeš nahlásit přes [veřejné Issues](https://github.com/HappyMistake64/Xcode-for-iphone/issues/new/choose). Pokud si nejsi jistý, zda chyba odhaluje soukromá data, použij soukromý formulář.
